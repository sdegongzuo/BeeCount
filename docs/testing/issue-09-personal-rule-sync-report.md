# Issue #9 个人规则同步与跨设备冲突验收记录

## 结论

个人提取规则、个人分类规则和个人备注偏好已经接入真实同步引擎。同步对象是不可变修订，不包含完整 OCR 或本机回归样本。新设备上的提取规则必须先通过本机回归；分类或备注目标冲突会暂停对应匹配范围，用户可在手机设置页查看候选并明确选择一个版本。

## 验收标准与证据

| 验收标准 | 实现与验证证据 |
| --- | --- |
| 同步三类个人规则，不上传完整 OCR | `SyncEngine` 的真实 push/pull 集成测试一次传输提取、分类、备注三类修订，并断言载荷不含 OCR、回归样本或敏感证据。 |
| 不可变修订保留来源与版本 | 修订首次落库时固定 `origin_device_id` 与由 SQLite 事务分配的单调 `origin_version`；并发写入仍保证递增，相同修订 ID 重试不改写版本，相同 ID 的不同内容被拒绝。 |
| 新设备提取规则保持待验证 | 远端提取修订在本机证据不足时进入 `pendingValidation`，不进入活动快照；候选规则必须由它自身完成本机回归，旧活动模板不能替它通过，冲突页也不能绕过门禁。 |
| 分类目标冲突暂停自动分类 | 相同作用域和条件、不同 `category_sync_id` 会写入暂停范围；图片生产创建链在页面规则、商户词典和关键词规则之前检查暂停，命中时使用“其他”并标记待分类。 |
| 提取冲突由本机回归裁决 | 同步引擎生产构造注入本机加密回归样本门禁；仅一条通过时启用通过者，证据不足或结果不兼容时保持暂停。 |
| 等价规则归档冗余修订 | 等价修订只物化一条活动规则，其余进入 `archivedEquivalent`；公共规则等价归档后重放旧远端修订也不会复活。 |
| 暂停范围进入待确认 | 命中暂停提取模板时写入稳定原因 `sync_extraction_conflict`，即使金额和时间齐全也进入待确认；分类冲突则创建“其他/待分类”账单。 |
| 覆盖离线并发、乱序和重复 | 同一修订集合的正序、逆序和重复到达收敛到相同状态；用户解决修订在另一设备乱序到达后解除暂停并物化同一目标。 |

所有候选都回归失败时，范围保持暂停并对用户可见；分类迁移预览以“活动物化规则 ∪ 不可变修订”的逻辑键并集计数，避免重叠多修订被重复统计。

同步引擎会把同一 pull 页中的个人修订一次性合并；分类或备注修订到达不会重复触发已下载提取规则的 500 样本回归。集成测试同时断言三条修订中只有一条提取修订时，本机回归门禁只调用一次。

## 普通用户解决流程

“设置 → 智能记账 → 个人规则冲突”展示冲突类型、匹配条件、作用范围和候选版本。分类候选显示本地分类名称而不是同步 UUID。用户确认后，App 在一个 SQLite 事务中完成以下操作：

1. 生成包含全部旧修订 ID 的新不可变解决修订；
2. 本机立即重新物化活动规则并解除暂停；
3. 保持解决修订为待上传，让其他设备在下次同步时收敛；
4. 物化失败时整体回滚，不遗留半成品修订。

远端提取候选额外要求本机回归通过；样本不足或验证失败时继续暂停并向用户显示稳定提示。

## 分类引用安全

分类删除同时检查活动物化规则与尚未解决的不可变同步修订，避免移除物化行后绕过引用保护。分类迁移会保留旧修订原文，并生成指向新分类稳定同步 ID 的解决修订；远端即使乱序收到旧修订和迁移修订，也只会物化新分类。
