# Triage Labels

工程技能使用五类标准 triage 角色。本文件把这些角色映射到本仓库 issue tracker 中实际使用的 label 字符串。

| 技能中的标准角色 | 本仓库 label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 描述完整，可以交给 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个 triage 角色时，使用上表右侧的 label 字符串。

如果将来仓库已有 label 词汇发生变化，只需要修改本文件右侧映射，不需要修改技能本身。
